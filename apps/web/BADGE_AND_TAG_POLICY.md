# Badge and Tag Policy

Forma uses compact labels only when they carry semantic load.

## Badge

Use `Badge` for metadata that changes interpretation or action:

- status: Open, Closed, Scheduled, Draft, Reviewed
- authority/provenance: Vatican, Diocese, Parish, CMS, YouTube
- file/media type: PDF, Video, Gallery, Dataset, API
- operational state: Livestream, Recurring, Machine-readable

Do not use `Badge` as decoration, emphasis, or a repeated section label.

## Tag

Use `Tag` for lightweight categorization, filters, language, dates, source metadata, or domain labels.

Do not use `Tag` only to make a layout feel visually fuller.

## Eyebrow

Use `Eyebrow` for section labels and registry categories.

## Text

Use normal `Text` when the information is descriptive rather than metadata.

## Test

A badge or tag should survive plain-text reading. If removing the pill styling makes the content feel redundant, it should probably be removed.
